# developer-tools

Central repository for AI governance assets and shared developer utilities.

## Structure

- `.github/copilot-instructions.md` — workspace-level Copilot instructions
- `.github/prompts/` — reusable `.prompt.md` files, selectable in Copilot Chat
- `.vscode/tasks.json` — shared VS Code tasks
- `.vscode/mcp.json` — MCP tool server configurations for Copilot agent mode
- `ai-governance/` — agent configs and AI usage policies
- `utilities/` — shared scripts, configs, and VS Code snippets
